## 📊 Featured Research

### Undergraduate Thesis

**Spatiotemporal Variability and Trends in Climatic Parameters and Their Association with Extreme Precipitation and Land Use/Land Cover Change in Northwest Bangladesh**

The study investigated long-term variability and trends in rainfall, temperature, relative humidity, and wind speed across **Rajshahi, Pabna, Natore, and Bogura**, along with extreme precipitation characteristics and LULC change.

**Methods included:**

* Mann–Kendall trend analysis
* Sen's slope estimation
* Generalized Extreme Value (GEV) analysis
* Correlation analysis
* GIS-based spatial analysis
* Landsat-based LULC analysis
